# 日语动词变形表

## 1. 辞书形

### 1.1 基本形式
**用法说明**：动词的原形，是所有变形的基础形式，通常出现在词典中，用于句子的终止或引用。
- **构成方法**：动词的原形
- **例子**：
  - 一类动词 (五段)：飲む（喝）、書く（写）、行く（去）
  - 二类动词 (一段)：食べる（吃）、見る（看）、寝る（睡觉）
  - 三类动词：する（做）、来る（来）

### 1.2 可能态 (能力表达)
**用法说明**：表示具备某种能力或可能性，相当于中文的"能"、"会"。
- **构成方法**：
  - 一类动词 (五段)：词尾的「う段」→「え段」+ る
  - 二类动词 (一段)：词尾 る → られる
  - 三类动词：する→できる，来る→来られる
- **例子**：
  - 一类动词 (五段)：飲む→飲める（能喝）、書く→書ける（能写）
  - 二类动词 (一段)：食べる→食べられる（能吃）、見る→見られる（能看）
  - 三类动词：する→できる（能做）、来る→来られる（能来）

## 2. 连用形

### 2.1 基本形式 (可能直接用)
**用法说明**：连接其他用言或构成复合动词，也可作为名词使用。
- **构成方法**：
  - 一类动词 (五段)：词尾的「う段」→「い段」
  - 二类动词 (一段)：词尾 る → （去掉る）
  - 三类动词：する→し，来る→来（き）
- **例子**：
  - 一类动词 (五段)：飲む→飲み（喝）、書く→書き（写）
  - 二类动词 (一段)：食べる→食べ（吃）、見る→見（看）
  - 三类动词：する→し（做）、来る→来（き）（来）

### 2.2 ます形 (礼貌形式)
**用法说明**：表示礼貌的陈述或疑问，用于正式场合或对长辈、上级说话时。
- **构成方法**：
  - 一类动词 (五段)：词尾的「う段」→「い段」+ ます
  - 二类动词 (一段)：词尾 る → ます
  - 三类动词：する→します，来る→来ます
- **例子**：
  - 一类动词 (五段)：飲む→飲みます（喝）、書く→書きます（写）
  - 二类动词 (一段)：食べる→食べます（吃）、見る→見ます（看）
  - 三类动词：する→します（做）、来る→来ます（来）

### 2.3 て形 (连接形)
**用法说明**：连接后续动词或形容词，表示动作的相继发生、并列或状态的持续。
- **构成方法**：
  - 一类动词 (五段)：词尾特殊变化
    - う、つ、る → って
    - む、ぶ、ぬ → んで
    - く/ぐ → いて/いで
    - す → して
  - 二类动词 (一段)：词尾 る → て
  - 三类动词：する→して，来る→来て
- **例子**：
  - 一类动词 (五段)：
    - う、つ、る：買う→買って（买了）、待つ→待って（等了）、売る→売って（卖了）
    - む、ぶ、ぬ：飲む→飲んで（喝了）、遊ぶ→遊んで（玩了）、死ぬ→死んで（死了）
    - く/ぐ：書く→書いて（写了）、聞く→聞いて（听了）、泳ぐ→泳いで（游了）、急ぐ→急いで（急了）
    - す：話す→話して（说了）、出す→出して（拿出了）
  - 二类动词 (一段)：食べる→食べて（吃了）、見る→見て（看了）
  - 三类动词：する→して（做了）、来る→来て（来了）

### 2.4 た形 (过去形)
**用法说明**：表示过去发生的动作或状态，相当于中文的"了"、"过"。
- **构成方法**：
  - 一类动词 (五段)：同て形变化，将て改为た
    - う、つ、る → った
    - む、ぶ、ぬ → んだ
    - く/ぐ → いた/いだ
    - す → した
  - 二类动词 (一段)：词尾 る → た
  - 三类动词：する→した，来る→来た
- **例子**：
  - 一类动词 (五段)：買う→買った（买了）、飲む→飲んだ（喝了）、書く→書いた（写了）、話す→話した（说了）
  - 二类动词 (一段)：食べる→食べた（吃了）、見る→見た（看了）
  - 三类动词：する→した（做了）、来る→来た（来了）

## 3. 未然形

### 3.1 基本形式(不直接用)
**用法说明**：未然形本身不单独使用，是构成否定、被动、使役等形式的基础。
- **构成方法**：
  - 一类动词 (五段)：词尾的「う段」→「あ段」，词尾为「う」时，变为「わ」
  - 二类动词 (一段)：词尾 る → ら
  - 三类动词：する→し，来る→来（こ）
- **例子**：无直接使用例子

### 3.2 ない形(否定形式)
**用法说明**：表示否定，相当于中文的"不"、"没有"。
- **构成方法**：
  - 一类动词 (五段)：词尾的「う段」→「あ段」+ ない，词尾为「う」时，变为「わ」
  - 二类动词 (一段)：词尾 る → ない
  - 三类动词：する→しない，来る→来ない
- **例子**：
  - 一类动词 (五段)：飲む→飲まない（不喝）、書く→書かない（不写）
  - 二类动词 (一段)：食べる→食べない（不吃）、見る→見ない（不看）
  - 三类动词：する→しない（不做）、来る→来ない（不来）

### 3.3 被动态
**用法说明**：表示被动，相当于中文的"被"、"受"。
- **构成方法**：
  - 一类动词 (五段)：词尾的「う段」→「あ段」+ れる，词尾为「う」时，变为「わ」
  - 二类动词 (一段)：词尾 る → られる
  - 三类动词：する→される，来る→来られる
- **例子**：
  - 一类动词 (五段)：飲む→飲まれる（被喝）、書く→書かれる（被写）
  - 二类动词 (一段)：食べる→食べられる（被吃）、見る→見られる（被看）
  - 三类动词：する→される（被做）、来る→来られる（被来）

### 3.4 使役态
**用法说明**：表示使役，相当于中文的"让"、"使"、"叫"。
- **构成方法**：
  - 一类动词 (五段)：词尾的「う段」→「あ段」+ せる，词尾为「う」时，变为「わ」
  - 二类动词 (一段)：词尾 る → させる
  - 三类动词：する→させる，来る→来させる（こさせる）
- **例子**：
  - 一类动词 (五段)：飲む→飲ませる（让喝）、書く→書かせる（让写）
  - 二类动词 (一段)：食べる→食べさせる（让吃）、見る→見させる（让看）
  - 三类动词：する→させる（让做）、来る→来させる（让来）

### 3.5 使役被动
**用法说明**：表示被迫做某事，相当于中文的"被迫"、"不得不"。
- **构成方法**：使役态词尾 る → られる
- **例子**：
  - 一类动词 (五段)：話す→話させられる（被迫说）、買う→買わされる（被迫买）
  - 二类动词 (一段)：食べる→食べさせられる（被迫吃）、見る→見させられる（被迫看）
  - 三类动词：旅行する→旅行させられる（被迫旅行）、来る→来させられる（被迫来）

## 4. 意志形
**用法说明**：表示说话人的意志、打算或提议，相当于中文的"要"、"想"、"我们...吧"。
- **构成方法**：
  - 一类动词 (五段)：词尾的「う段」→「お段」+ う
  - 二类动词 (一段)：词尾 る → よう
  - 三类动词：する→しよう，来る→来よう（こよう）
- **例子**：
  - 一类动词 (五段)：行く→行こう（要去）、飲む→飲もう（要喝）
  - 二类动词 (一段)：食べる→食べよう（要吃）、見る→見よう（要看）
  - 三类动词：読書する→読書しよう（要读书）、来る→来よう（要来吧）

## 5. 命令形

### 5.1 命令
**用法说明**：表示命令，语气较为强硬，用于上级对下级、长辈对晚辈的场合。
- **构成方法**：
  - 一类动词 (五段)：词尾的「う段」→「え段」
  - 二类动词 (一段)：词尾 る → ろ
  - 三类动词：する→しろ，来る→こい
- **例子**：
  - 一类动词 (五段)：行く→行け（去吧）、書く→書け（写吧）
  - 二类动词 (一段)：食べる→食べろ（吃吧）、見る→見ろ（看吧）
  - 三类动词：勉強する→勉強しろ（学习吧）、来る→こい（过来）

### 5.2 禁止
**用法说明**：表示禁止，相当于中文的"不要"、"禁止"。
- **构成方法**：在辞书形后面直接加 な
- **例子**：
  - 一类动词 (五段)：行く→行くな（不要去）、書く→書くな（不要写）
  - 二类动词 (一段)：食べる→食べるな（不要吃）、見る→見るな（不要看）
  - 三类动词：勉強する→勉強するな（不要学习）、する→するな（不要做）

## 6. 假定形
**用法说明**：表示假设或条件，相当于中文的"如果"、"假如"、"要是...的话"。
- **构成方法**：
  - 一类动词 (五段)：词尾的「う段」→「え段」+ ば
  - 二类动词 (一段)：词尾 る → れば
  - 三类动词：する→すれば，来る→来れば
- **例子**：
  - 一类动词 (五段)：話す→話せば（如果说）、行く→行けば（如果去）
  - 二类动词 (一段)：食べる→食べれば（如果吃）、見る→見れば（如果看）
  - 三类动词：仕事する→仕事すれば（如果工作）、来る→来れば（如果来）
