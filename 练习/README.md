# 日语语法练习体系说明（初级下册）

> 面向未来在本仓库内「自动出题 + 自评」的约定说明。  
> 主要服务对象：Agent / 人类自己出题时的统一规范。

---

## 目标与范围

- 覆盖：《新版 中日交流标准日本语 初级 下册》（第25〜48课）的主要语法点。
- 依据：
  - `总结归纳/新标日下册语法汇总.md`（语法树 + 例句总表）
  - `新标日初级/第XX课: ….md`（每课完整课文与语法解释）
  - `standard.yaml`（书面日语能力评估与打分标准）
- 输出物：按日期归档的练习单，例如：
  - `练习/2025-11-16/practice-01.md`
  - `练习/2025-11-16/practice-02.md`

---

## 出题入口类型

后续给 Agent 的指令，推荐统一为以下三类之一（可组合）：

1. **按课程出题**
   - 指定：某一课或若干课，如「第29课」「第29〜30课」。
   - 依据：  
     - `新标日初级/第29课: 電気を消せ.md`  
     - `总结归纳/新标日下册语法汇总.md` 中对应章节。

2. **按语法点出题**
   - 指定：语法描述标签，如：
     - 「命令形」「〜なさい」「〜ように」「〜はずがありません」等。
   - Agent 应在 `新标日下册语法汇总.md` 中搜索对应语法点，并列出涉及的课文与例句后再设计题目。

3. **按评估维度出题（配合 standard.yaml）**
   - 指定：`standard.yaml` 中的某些叶子节点或大类，例如：
     - `A1-2 未然形（否定/受身/使役/使役受身）`
     - `A2-3 条件句（〜たら／〜ば／〜なら／〜と）`
   - Agent 应把这些维度映射到《语法汇总》中的相关语法点，再设计覆盖这些变化的题型。

---

## 目录与命名约定

- 每天的练习放在独立文件夹下：
  - 目录名：`练习/YYYY-MM-DD/`
  - 文件名：`practice-01.md`, `practice-02.md` ……
- 一个 `practice-XX.md` 定义为**一套练习**，内部包含：
  - 出题依据与目标说明
  - 题目本体（按 T1/T2/T3 模块组织）
  - 形成性评价卡（对应 `standard.yaml` 的打分卡格式）

---

## 练习单结构约定（概览）

详见：`练习/模版-练习单.md`，这里只给结构概要：

1. **元信息区**
   - 日期、套题编号、来源课文（路径）、目标语法点列表。
2. **任务区**
   - T1：识别/填空题（形态、助词、基本句型）
   - T2：改写/互改题（肯↔否、时体、敬体→常体、合用/拆分等）
   - T3：微写作/翻译/回应（80〜120字，要求使用指定语法点）
3. **形成性评价卡**
   - 表格列严格遵照 `standard.yaml` 中「形态A_综合卡」的顺序：
     - `大类｜小类｜具体要点｜分数｜证据(优势或劣势)`
   - 可选附加列：`ACC/NAT/ROB｜下一步动作`

## 试卷格式规范（Markdown 版）

> 这里的「试卷」指一整套练习（对应一个 `practice-XX.md` 文件），无论是 Agent 以 Markdown 直接输出，还是落盘到 `练习/YYYY-MM-DD/`。

### 1. 标题与元信息

- 顶部推荐使用一级或二级标题：
  - `# 新标日初级下册 语法练习（第29課・命令形）`
  - 或由 Agent 自动生成类似：  
    `# [YYYY-MM-DD] 日本语语法练习 practice-01`
- 紧接一个「练习元信息」小节（模板已给出）：
  - 指出 **参考资料路径**、**考察语法点列表**、**关联的 standard.yaml 维度**。

### 2. 题目区块的分节格式

- 必须按顺序分成三个大部分，并用二级标题标明：
  - `## T1：识别・填空`
  - `## T2：改写・对比`
  - `## T3：微写作／输出任务`
- 如需要更多部分（例如听力、阅读），可以继续使用 `## T4：……`，但前三部分的含义尽量保持与 `standard.yaml` 中 T1/T2/T3 一致。

### 3. 单题格式（编号与语法标签）

- 每道题用阿拉伯数字编号，统一前缀：
  - `1.` `2.` `3.` ……（嵌套列表也可以，但首层编号应连续）。
- 推荐在题干开头用小标签注明考察点，方便之后统计：
  - 例如：  
    `1. 【★ 命令形・29课】次の動詞を命令形にしなさい。`  
    `2. 【★★ 〜ように・38课】文脈に合うように書き換えなさい。`
  - 推荐使用难度标签：`★`（提示多、形式简单）、`★★`（有提示但需一定推理）、`★★★`（几乎无提示或开放式作答）。
- 多项选择题的选项格式：
  - 每个选项独立成行，使用大写字母前缀：  
    `A. ...`  
    `B. ...`  
    `C. ...`
- 填空题统一使用括号表示作答区域，尽量贴近真实考试形式：
  - 使用全角括号的空格：`電気を（　　　）。`
  - 不再使用下划线 `＿＿＿＿` 与括号混写，避免视觉噪音和版式干扰。
- 若需要给出“应使用的词或语法点”，统一放在句子**末尾**，而不是插入句中：
  - ✅ `これは明日会議で（　　　）資料です。　動詞：使う`
  - ✅ `友達に手紙を（　　　）、辞書を一冊買いました。　文型：〜ために`
  - ❌ `これは明日会議で（使う）＿＿＿＿資料です。`
- 题干中**不要直接给出正确答案的变形**，括号中若给出动词或形容词，应使用辞書形或词干，而不是已经变好的形式：
  - ✅ `わたしが昨日（撮る）資料を、メールで送りました。`
  - ❌ `わたしが昨日（撮った）資料を、メールで送りました。`
- 若需要示范完整正确答案，请单独用「例：〜」行展示，不要和正式题目写在同一行：
  - 例：`例：日曜日は本を読んだり、散歩したりします。`
  - 正式题目：`休みの日は、友達と（　　　）たり、映画を（　　　）たりします。　動詞：遊ぶ／見る`

### 4. 参考答案与解析

- 默认情况下，`practice-XX.md` 只包含题目与「空的答案区块」，**不直接写出参考答案**，以便用于盲练。
- 若确有需要在同一文件中给出答案，建议单独设一节，与题目部分通过标题清楚隔离：
  - `## 参考答案与点评`
  - 按 T1/T2/T3 分段列出答案：
    - `T1-Q1: ...`、`T2-Q3: ...`
- 也可以将答案放在单独文件中，例如：  
  - 题目：`practice-01.md`  
  - 答案：`practice-01-answers.md`
- 对于关键语法点，推荐在答案后加一两句简短解析：
  - 例：`※ 命令形は五段動詞語幹＋え、例：書く→書け。`

### 5. 形成性评价卡区块

- 评价卡建议放在文件末尾，并用独立标题：
  - `## 形成性评价卡`
- 必须包含一张 Markdown 表格，其列顺序遵照：
  - `大类｜小类｜具体要点｜分数｜证据(优势或劣势)`
- 如果 Agent 当场给出评分，应在「证据」中引用本试卷具体题目或句子作为依据；
  - 例：`命令形变形 5/6 正确；Q3 将「食べる」误写为「食べれ」。`

### 6. 翻译题与难度分级（推荐）

- 每套练习建议至少包含 **2 道中文→日文翻译题**（可集中在 T2/T3，也可分散在 T1/T2/T3）。
- 翻译题应在题头用难度标签标明预期难度，并说明是否指定语法点或关键词：
  - `【★ 中译日・〜ために】`：给出目标语法或关键词，句子结构较简单。  
    - 例：`【★ 中译日・〜ために】请用「〜ために」翻译：为了通过考试，我每天学习日语。`
  - `【★★ 中译日・条件句】`：只提示语法类型或给出日文开头，不给出完整日文关键词。  
    - 例：`【★★ 中译日・〜たら／〜ても】请根据语境选择合适的条件形式进行翻译。`
  - `【★★★ 中译日・综合】`：只给中文和场景，不指定具体语法，由学习者自行选择合适表达。  
    - 例：`【★★★ 中译日】请描述一次你改变计划的经历，至少使用两个本单元学过的语法。`
- 对于指定语法的翻译题，题干中要明确写出「请使用〜」「请至少使用一次〜」，方便之后在评价卡中对照打分。

## Agent 出题工作流（简要）

1. 解析用户指令，确定：
   - 目标课文／语法点／评估维度；
   - 目标 StyleProfile（若用户未指定，默认 `domain=学术 or 评测/说明, formality=neutral, politeness=常体/ですます 混合`）。
2. 在项目文件中/互联网上检索并汇总素材, 并在对应试卷中以以下格式进行引用说明：
   - `总结归纳/新标日下册语法汇总.md`
   - 对应的 `新标日初级/第XX课: ....md`
   - 网络资料
3. 按 `standard.yaml` 的「任务梯度与取样」：
   - T1：6〜10 题（识别/填空）；
   - T2：3〜5 题（改写/互改）；
   - T3：1 段微写作或综合输出。
4. 使用 `练习/模版-练习单.md` 生成 `YYYY-MM-DD/practice-XX.md`：
   - 明确写出**考察的语法点**与**对应课文例句**；
   - 在题目后留出「参考答案/点评」区（可由 Agent 或人类事后填写）。
5. 根据完成情况、错误类型，填写底部的「形成性评价卡」。

后续如果你有新的题型或评价需求，可以在本目录增加补充说明或新的模板文件。
