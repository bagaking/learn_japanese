## 第47课: 周先生は明日日本へ行かれます

> 主要讲的内容: 日语尊他语（尊敬語）的基本用法

### 基本课文

1. 周先生は明日日本へ**行かれます**。
2. お客様はもう**お帰りになりました**。
3. どうぞ**お座りください**。
4. 先生、何を**召し上がります**か。

### 对话部分

- 甲：お土産はもう**買われました**か。
- 乙：はい、買いました。

- 甲：あのう、靴売り場は何階ですか。
- 乙：4階で**ございます**。

- 甲：小野さん、木村部長は何時に戻って**おいでになりました**か。
- 乙：木村部長ですか。先ほど戻って**いらっしゃいました**よ。

### 语法解释

> 主要语法现象: 尊他语的三种构成方式

#### 语法点1: 动词被动形用作尊他语（れる/られる形）

- **规则**: 动词被动形式（れる/られる形）可以作为尊他语使用。
- **变形规则**:
    - **一类动词**: 未然形 + れる
        - 行く → 行か**れる**
        - 買う → 買わ**れる**
    - **二类动词**: 未然形 + られる
        - 食べる → 食べ**られる**
        - 見る → 見**られる**
    - **三类动词**:
        - 来る → 来**られる**（こられる）
        - する → さ**れる**
- **例句**:
    - 周先生は明日日本へ**行かれます**。（周老师明天要去日本。）
    - お土産はもう**買われました**か。（您已经买特产了吗？）

#### 语法点2: お + 动词[ます形] + になる [郑重尊他语]

- **规则**: 更郑重的尊他语表达方式。
- **构成**: お + 动词ます形（去掉ます） + になる
- **例句**:
    - お客様はもう**お帰りになりました**。（客人已经回去了。）
    - どうぞ**お座りください**。（请坐。）
    - 何時に戻って**おいでになりました**か。（您什么时候回来的？）

#### 语法点3: 特殊尊他语动词

- **规则**: 一些常用动词有特殊的尊他语形式。
- **常见特殊尊他语**:
    - 行く/来る/いる → **いらっしゃる**
    - する → **なさる**
    - 食べる/飲む → **召し上がる**
    - 言う → **おっしゃる**
- **例句**:
    - 先生、何を**召し上がります**か。（老师，您要吃点什么？）
    - 木村部長は先ほど戻って**いらっしゃいました**。（木村部长刚才回来了。）

#### 语法点4: 郑重语表达（ございます）

- **规则**: "です"的郑重语形式是"でございます"。
- **用法**: 比"です"更加礼貌、正式。
- **例句**:
    - 靴売り場は4階で**ございます**。（鞋类卖场在4楼。）

### 表达及词语讲解

> 补充说明和实际应用

#### 1. 尊他语的使用场合

- 对长辈、上级、客户等需要表示尊敬的人使用
- 正式场合、商务场合必须使用
- 日常会话中对熟悉的人可以不用

#### 2. 三种尊他语形式的敬意程度比较

1. **特殊尊他语动词**（いらっしゃる、召し上がる等）：最高敬意
2. **お～になる形式**：中等敬意，使用广泛
3. **れる/られる形式**：基本敬意，较为简洁

#### 3. 实用注意事项

- 尊他语不能用于说话人自己的动作
- 要根据对象和场合选择合适的敬意程度
- 避免过度使用造成不自然

#### 4. 重点尊他语动词对照表

| 普通动词       | 尊他语形式     | 例句                             |
|----------------|----------------|----------------------------------|
| 行く、来る、いる | いらっしゃる   | 部長はもう**いらっしゃいます**か      |
| する           | なさる         | 何を**なさいます**か                |
| 食べる、飲む     | 召し上がる     | どうぞ**召し上がって**ください        |
| 言う           | おっしゃる     | 先生がそう**おっしゃいました**       |

### 词汇扩展

> 职场相关尊他语词汇

#### 职务名称

- 社長（总经理、社长）
- 副社長（副总经理、副社长）
- 部長（部长）
- 課長（科长）
- 係長（股长）

#### 部门名称

- 総務部（总务部）
- 人事部（人事部）
- 経理部（经理部）
- 営業部（营业部）
- 広報部（公关部）

#### 商务场合常用表达

- お世話になっております（承蒙关照）
- よろしくお願いいたします（请多关照）
- かしこまりました（明白了）
- 承知いたしました（知道了）
