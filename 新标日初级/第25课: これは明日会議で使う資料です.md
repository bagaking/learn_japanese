## 第25课: これは明日会議で使う資料です

> 主要讲的内容: 日语中的长定语处理（小句修饰名词）

### 课文

1. これは明日会議で使う資料です
2. わたしが明日乗る飛行機は中国航空です。
3. 中国で買ったCDを友達に貸しました。
4. 操作が簡単なパソコンが欲しいです。

### 情景对话

- 甲：李さん、この人はだれですか。
- 乙：その人は中国でとても人気がある女優です。

- 甲：あの窓のところにいる人はだれですか。
- 乙：あれは受付の戴さんですよ。

- 甲：何をしているんですか。
- 乙：昨日李さんにもらった本を読んでいます。

- 甲：この会社で歌がいちばん上手な人はだれですか。
- 乙：森さんだと思います。

### 语法解释

> 主要语法现象: 小句（动词/形容词/名词简体形）修饰名词

#### 语法点1: 小句（动词简体形）+ 名

- **规则**: 动词或由动词做谓语的小句修饰名词时，使用动词的简体形。
    - 表示习惯或未来动作时，用动词**基本形**。
    - 表示动作已完成时，用动词**た形**。
- **注意**:
    - 名词前绝对不使用敬体形（如～ます、～です）。
    - 动词小句与所修饰的名词之间**不能加**“の”。
- **例句**:
    - わたしが明日**乗る飛行機**は中国航空です。（我明天要乘坐的飞机是中国航空。）
    - 小野さんが**作る料理**はおいしいです。（小野女士做的菜很好吃。）
    - 中国で**買ったCD**を友達に貸しました。（把在中国买的CD借给了朋友。）
    - 森さんが**買った本**はこれです。（森先生买的书是这本。）

#### 语法点2: 小句（动词简体形）+ 名 は 名 / 形 です

- **规则**: 由动词小句修饰名词所构成的名词短语，经常在句子中充当**主语**。
- **例句**:
    - わたしが明日乗る**飛行機は**中国航空です。
    - 小野さんが作る**料理は**おいしいです。
    - 森さんが買った**本は**これです。

#### 语法点3: 小句（动词简体形）+ 名 を/に/から 动ます

- **规则**: 由动词小句修饰名词所构成的名词短语，也可以充当主语以外的其他句子成分（如宾语、对象等）。
- **例句**:
    - 中国で買った**CDを**友達に貸しました。（把在中国买的CD借给了朋友。）
    - 知らない**人から**手紙が来ました。（收到了一个不认识的人的来信。）

#### 语法点4: 修饰名词的动词小句中的主语

- **规则**: 在修饰名词的动词小句内部，表示主语时使用“**が**”，而**不能使用**“は”。
- **例句**:
    - わたし**が**知らない人 （我不认识的人） (○)
    - わたし**は**知らない人 (×)
    - 森さん**が**買った本 （森先生买的书）(○)
    - 森さん**は**買った本 (×)

#### 语法点5: 小句（一类形容词/二类形容词/名词） + 名

- **规则**:
    1.  “名 + が + 一类形容词 + です”修饰名词时，一类形容词使用**基本形**。
    - **例句**: 入り口が**広い**あの建物がわたしの会社です。（入口很宽敞的那栋楼是我的公司。）
    2.  “名 + が + 二类形容词 + です”修饰名词时，要变为“二类形容词 + **な**”的形式。
    - **例句**: 操作が**簡単な**パソコンが欲しいです。（我想要操作简单的电脑。）
    3.  “名1 + が + 名2 + です”修饰名词时，要变为“名2 + **の**”的形式。
    - **例句**: 数学が**専門の**先生が休みました。（教数学的老师休息了。）
- **注意**: 与汉语的“的”不同，日语中的形容词（一类形、二类形）修饰名词时，**不能加**“の”。
    - 入り口が広いあの建物 (○)
    - 入り口が広いのあの建物 (×)
    - 操作が簡単なパソコン (○)
    - 操作が簡単なのパソコン (×)
