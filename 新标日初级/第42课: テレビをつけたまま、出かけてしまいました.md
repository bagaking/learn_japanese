## 第42课: テレビをつけたまま、出かけてしまいました

> 主要讲的内容: 状态保持（～まま）、转折（～のに）、推测（～はず）、否定推测（～はずがない）

### 基本课文

1. テレビをつけたまま、出かけてしまいました。
2. 目覚ましをかけておいたのに、今朝は起きられませんでした。
3. 会議は5時までですから、もうすぐ終わるはずです。
4. 張さんは入院中ですから、旅行に行くはずがありません。

### 对话部分

- 甲：昨日、窓を開けたまま寝たので、風邪を引いてしまいました。
- 乙：それはいけませんね。お大事に。

- 甲：すみません、このパソコン、電源を入れたのに動かないんですが...
- 乙：ああ、そのパソコンは壊れています。

- 甲：森さんはどこですか。
- 乙：1時間ほど前に会社を出ましたから、もう着いているはずです。

- 甲：お母さん、遅いですね。
- 乙：この家は駅から近くて便利なので、買う人が来ないはずがありません。

### 语法解释

> 主要语法现象: 状态保持、转折、推测表达

#### 语法点1: 小句（动词た形/ない形） + まま

- **规则**: "～まま"表示在某种状态持续的情况下进行另一动作。
- **接续方式**:
    - 动词た形 + まま
    - 动词ない形 + まま
- **意义**: 表示保持原样、原封不动
- **例句**:
    - テレビを**つけたまま**、出かけてしまいました。（开着电视就出门了。）
    - 窓を**開けたまま**寝たので、風邪を引いてしまいました。（开着窗户睡觉，所以感冒了。）
    - 馬さんはどこへ行くか言わ**ないまま**、家を出ました。（小马没说去哪里就离开了家。）

#### 语法点2: 小句（简体形） + のに

- **规则**: "～のに"表示转折，相当于"虽然……但是……"，含有意外、不满、遗憾等语气。
- **接续方式**:
    - **动词/一类形容词小句**: 简体形 + のに
    - **二类形容词小句**: 词干 + **な** + のに
    - **名词小句**: 名词 + **な** + のに
- **例句**:
    - 目覚ましをかけて**おいたのに**、今朝は起きられませんでした。（虽然设了闹钟，但今早还是没起来。）
    - 電源を**入れたのに**動かないんですが...（虽然开了电源却不运转……）
    - 田中さんは作家**なのに**、読書が嫌いです。（田中先生虽然是作家，却讨厌读书。）

#### 语法点3: 小句（简体形） + はずです

- **规则**: 表示根据某种理由做出有把握的推测。
- **接续方式**:
    - **动词/一类形容词小句**: 简体形 + はずです
    - **二类形容词小句**: 词干 + **な** + はずです
    - **名词小句**: 名词 + **の** + はずです
- **用法**:
    - 用于说话人对自己推测的内容很有把握的情况
    - 也可用于记忆不十分准确但根据情况推断
- **例句**:
    - 会議は5時までですから、もうすぐ**終わるはずです**。（会议5点结束，应该快完了。）
    - この映画は人気がありますから、観客は**多いはずです**。（这部电影很受欢迎，观众应该很多。）
    - キムさんはこの大学の学生**のはずです**。（金女士应该是这所大学的学生。）

#### 语法点4: 小句（简体形） + はずがありません

- **规则**: "～はずがありません"是"～はずです"的否定形式，表示根据某种理由做出否定的推断。
- **接续方式**: 与"～はずです"相同
- **口语形式**: 也可以说成"～はずがない"
- **例句**:
    - 張さんは入院中ですから、旅行に**行くはずがありません**。（小张在住院，不可能去旅行。）
    - 7月のオーストラリアは冬ですから、**暑いはずがありません**。（7月的澳大利亚是冬天，不可能热。）
    - 森さんはスキーがあんなに上手ですから、**初心者のはずがありません**。（森先生滑雪那么好，不可能是初学者。）

### 表达及词语讲解

> 补充说明和实际应用

#### 1. ～まま的用法扩展

- 可以表示"按照原样"的意思
    - 昔の**まま**の町並み（保持原样的街道景观）
- 与"～たきり"的区别：～まま强调状态保持，～たきり强调"一次之后再也不"

#### 2. ～のに的特殊语气

- 含有意外、不满、遗憾、责怪等感情色彩
- 比"しかし"、"でも"的语气更强
- 常用于抱怨、责备的场合

#### 3. ～はず的把握程度

- 表示基于客观事实的合理推测
- 把握程度高于"でしょう"，低于"に違いない"
- 可以用于确认自己的记忆：確かここに置いたはず（应该是在这里）

#### 4. 实用表达补充

- 目覚ましをかける：上闹钟
- お大事に：请多保重（对病人说）
- ～ほど：大约（时间程度）
- せっかく～のに：好不容易……却……

#### 5. 重点词汇

- つける（打开）
- 目覚まし（闹钟）
- 入院中（住院中）
- 責任者（负责人）
- 初心者（初学者）
