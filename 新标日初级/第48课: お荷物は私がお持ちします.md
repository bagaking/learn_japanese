## 第48课: お荷物は私がお持ちします

> 主要讲的内容: 日语自谦语（謙譲語）的基本用法

### 基本课文

1. お荷物は私が**お持ちします**。
2. 明日、私が**伺います**。
3. 黄教授に論文を**見ていただきました**。
4. 何か**お手伝いすることがあります**か。

### 对话部分

- 甲：昨日、メールを**お送りした**んですが…
- 乙：ええ、**拝見しました**。先ほど返事を**お出ししました**。

- 甲：どちらから**いらっしゃった**ですか。
- 乙：中国の北京から**参りました**。

- 甲：そろそろ**失礼いたします**。
- 乙：どうぞ**お構いなく**。**お邪魔いたしました**。

- 甲：この服、ちょっと小さいので、取り替えて**いただけます**か。
- 乙：**承知いたしました**。少々**お待ちください**。

### 语法解释

> 主要语法现象: 自谦语的三种构成方式

#### 语法点1: お + 动词[ます形] + します [基本自谦语]

- **规则**: 通过压低说话人自身动作来表示对对方的尊敬。
- **构成**: お + 动词ます形（去掉ます） + します/いたします
- **例句**:
    - お荷物は私が**お持ちします**。（我来帮您拿行李。）
    - メールを**お送りしました**。（我已经给您发了邮件。）
    - 返事を**お出ししました**。（我已经给您回信了。）

#### 语法点2: 特殊自谦语动词

- **规则**: 一些常用动词有特殊的自谦语形式。
- **常见特殊自谦语**:
    - 行く/来る → **伺う**/**参る**
    - いる → **おる**
    - する → **いたす**
    - 見る → **拝見する**
    - 聞く → **伺う**
    - 食べる/飲む → **いただく**
    - 言う → **申す**/**申し上げる**
- **例句**:
    - 明日、私が**伺います**。（明天我去拜访您。）
    - 中国の北京から**参りました**。（我来自中国北京。）
    - メールを**拝見しました**。（我已经拜读了您的邮件。）

#### 语法点3: ～ていただきます [谦逊请求]

- **规则**: 表示请求对方为自己做某事，是谦逊的表达方式。
- **构成**: 动词て形 + いただきます
- **例句**:
    - 黄教授に論文を**見ていただきました**。（我请黄教授看了我的论文。）
    - 取り替えて**いただけます**か。（能请您帮我换一下吗？）
    - お知らせを**いただけます**か。（能请您通知我吗？）

#### 语法点4: お + 动词[ます形] + ください [礼貌请求]

- **规则**: 礼貌地请求对方做某事。
- **构成**: お + 动词ます形（去掉ます） + ください
- **例句**:
    - 少々**お待ちください**。（请您稍等片刻。）
    - どうぞ**お座りください**。（请您坐下。）

### 表达及词语讲解

> 补充说明和实际应用

#### 1. 自谦语的使用场合

- 用于描述说话人自己或自己一方的动作
- 通过压低自己来表示对对方的尊敬
- 在商务场合、正式场合必须使用

#### 2. 自谦语与尊他语的区别

- **尊他语**: 抬高对方动作（第47课）
- **自谦语**: 压低自己动作（本课）
- 两者不能混淆使用

#### 3. 常用自谦语动词对照表

| 普通动词   | 自谦语形式   | 例句                  |
|------------|--------------|-----------------------|
| 行く、来る | 伺う、参る     | 明日**伺います**        |
| いる       | おる         | 田中で**おります**      |
| する       | いたす       | 私が**いたします**      |
| 見る       | 拝見する     | メールを**拝見しました**  |
| 聞く       | 伺う         | お名前を**伺います**     |
| 食べる、飲む | いただく     | お菓子を**いただきます** |

#### 4. 名词、形容词的敬语形式

- 在名词和形容词前加"お"或"ご"
- 日语固有词前一般加"お"
- 汉字词前一般加"ご"
- **例**: お食事、ご利用、ご家族、ご招待

### 词汇扩展

> 自谦语相关词汇

#### 常用自谦表达

- 失礼いたします（告辞了）
- お邪魔いたしました（打扰您了）
- 承知いたしました（知道了）
- 何のお構いもしませんで（招待不周）

#### 商务场合常用自谦语

- お待たせいたしました（让您久等了）
- 恐れ入ります（不好意思）
- かしこまりました（明白了）
- 承りました（收到您的吩咐）

#### 重点词汇解释

- 少々（稍许）
- 伺う（拜访、请教）
- 参る（来、去）
- 拝見する（拜读、观看）
- 承知する（知道、同意）

### 注意事项

1. **自谦语只能用于自己**：描述自己或自己一方的动作
2. **根据对象选择敬意程度**：对客户要用最高敬语
3. **避免过度使用**：在熟悉的人之间可以适当简化
4. **注意动词搭配**：特殊自谦语动词需要单独记忆

通过本课学习，可以掌握在正式场合中恰当使用自谦语来表达对对方的尊重。
