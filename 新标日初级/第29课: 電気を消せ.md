## 第29课: 電気を消せ

> 主要讲的内容: 命令与禁止的表达方式（命令形、禁止形、～なさい、～て/～ないで）

### 基本课文

1.  電気を消せ。
2.  次の文章を読んで，質問に答えなさい。
3.  ここに車を止めるな。
4.  このマークは「タバコを吸うな」という意味です。

### 对话部分

- 甲：さっき部長は何と言いましたか。
- 乙：「書類を早く提出しろ」と言いました。

- 甲：誠，早くお風呂に入りなさい。
- 乙：今宿題しているんだ。お母さん先に入ってよ。

- 甲：すみません，これは何と読みますか。
- 乙：「たちいりきんし（立入禁止）」と読みます。「ここに入るな」という意味ですよ。

- 甲：この花の名前を知っていますか。
- 乙：ええ，それはフジという花です。

### 语法解释

> 主要语法现象: 命令、禁止、祈使的表达方式

#### 语法点1: 动词的命令形

- **定义**: 说话人对听话人下命令时使用的表达形式。
- **变形规则**:
    - **一类动词**: 把基本形的最后一个音变成相应的“え”段上的音。
        - 例: 行く → 行**け**、書く → 書**け**
    - **二类动词**: 把基本形的“る”变成“ろ”。
        - 例: 食べ**る** → 食べ**ろ**、見**る** → 見**ろ**
    - **三类动词**:
        - 来る → 来**い**（こい）
        - する → **しろ**
- **例句**:
    - **電気を消せ**。（把灯关了！）
    - **早く片付けろ**。（快点收拾！）
    - **書類を早く提出しろ**。（快点交文件！）

#### 语法点2: 动[ます形] + なさい

- **规则**: 比命令形稍微礼貌一些的命令表达方式。由动词“ます形”去掉“ます”后加“なさい”构成。
- **语气**: 常用于**长辈对晚辈**（如父母对孩子、老师对学生）的场景。
- **例句**:
    - 早く**お風呂に入りなさい**。（快去洗澡！）
    - 次の文章を読んで，質問に**答えなさい**。（读下面的文章，然后回答问题！）

#### 语法点3: 动[基本形] + な [禁止]

- **规则**: 用于**禁止**听话人做某事。在动词基本形后面直接加“な”。
- **注意**: 语气非常强硬，使用时需注意场合和对象。
- **例句**:
    - ここに車を**止めるな**。（不要在这里停车！）
    - タバコを**吸うな**。（不要吸烟！）
    - ここに**入るな**。（禁止入内！）

#### 语法点4: 动[て形] / 动[ない形] + で [祈使]

- **规则**: “动词て形”或“动词ない形＋で”是日常生活中经常使用的、语气相对缓和的祈使表达。
    - “动词て形”：表示“请……”。
    - “动词ない形＋で”：表示“请不要……”。
- **使用场景**: 不论男性、女性都经常使用，但一般用于**关系亲密的人之间**。
- **例句**:
    - もうちょっと**急いで**。（再稍微快一点！）
    - ちゃんと話を**聞いて**。（好好听我说！）
    - 遠慮**しないで**。（别客气！）
    - お母さん先に**入って**よ。（妈妈你先洗吧。）

#### 语法点5: 名1 + という + 名2

- **规则**: 在提供对方不知道的新信息时，将表示新信息的词语（名1）后面加上“という”，再后续需要说明的名词（名2）。
- **功能**: 用于解释或说明事物名称、内容等。
- **例句**:
    - このマークは「タバコを吸うな」**という意味**です。（这个标记是“禁止吸烟”的意思。）
    - 「立入禁止」は「ここに入るな」**という意味**です。（“立入禁止”是“禁止入内”的意思。）
    - それは**フジという花**です。（那是叫做“紫藤”的花。）

### 表达及词语讲解

#### 1. 命令形、禁止形的用法

- 命令形和禁止形给人一种**粗鲁的印象**，使用场合很受限制，但在特定情况下有必要使用：
    - **男性为主的工作单位**：上司对部下，长辈对晚辈以及同辈之间。
        - 例: おい、早く片づけ**ろ**。（喂，快点收拾！）
    - **关系亲密的男性朋友之间**。
        - 例: さぁ、もっと飲め**よ**。（来，多喝点！）
    - **紧急场合**（即使对上级或尊长也可使用）。
        - 例: 危ない！止まれ**！**（危险！快停下！）
        - 注意：女性在紧急时多用“动词て形”（如：止まって！）或“动词ない形＋で”（触らないで！）。
    - **观看体育比赛**为选手加油时（男女都可能使用）。
        - 例: 頑張**れ**！（加油！）
    - **直接引用**含有祈使意义的话语或**解释词语**时（男女均可）。
        - 例: 部長は「書類を早く提出し**ろ**」と言いました。（部长说“快交文件”。）

#### 2. “～ないといけません”的省略形式

- **规则**: 在口语中，“～ないといけません”（必须…）、“～なければなりません”（必须…）等较长表达常被省略。
    - “～ないといけない”可省略为“～ないと”。
    - “～なければならない”可省略为“～なければ”。
- **例句**:
    - 早く言わ**ないと**（いけない）ね。（必须早点说啊。）
    - 勉強し**なければ**（なりません）。（必须学习。）
