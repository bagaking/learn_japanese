## 第27课: 子供の時、大きな地震がありました

> 主要讲的内容: 时间表达（小句+時）、同时动作（ながら）、确认表达（でしょう）、习惯动作（ています）

### 基本课文

1. 子供の時、大きな地震がありました。
2. 映画を見る時、いつもいちばん後ろの席に座ります。
3. 李さんはテレビを見ながら食事をしています。
4. 李さん、明日パーティーに行くでしょう？

### 对话部分

- 甲：学生の時、何を勉強しましたか。
- 乙：日本の経済について勉強しました。

- 甲：馬さん、暇な時、この書類を整理してください。
- 乙：はい、分かりました。

- 甲：葉子さんはアルバイトをしながら学校に通っているんですよ。
- 乙：そうですか。なかなか大変ですね。

- 甲：森さん、昨日、駅前の喫茶店にいたでしょう。
- 乙：はい。仕事で、楊さんと会っていたんです。

### 语法解释

> 主要语法现象: 时间从句、同时动作、确认、习惯性动作

#### 语法点1: 小句(简体形) + 時

- **规则**: “小句+時”构成表示时间的名词短语。
    - **动词小句**:
        - “～する（基本形）＋時”：后项动作发生时，前项动作**尚未完成**。
        - “～した（た形）＋時”：后项动作发生时，前项动作**已经完成**。
    - **一类形容词小句**：用简体形直接连接“時”。
    - **二类形容词/名词小句**：用“二类形容词词干 + な + 時”或“名词 + の + 時”的形式。
- **注意**：只有名词修饰“時”时加“の”（如：子供の時）。动词、形容词修饰时一律不能加“の”（×～するの時、×忙しいの時）。
- **参考**：表示一次性、个别情况时，可在“～時”后加“に”（～時に）。
- **例句**:
    - 映画を**見る時**、いつもいちばん後ろの席に座ります。（看电影时，总是坐最后一排。）
    - この前、友達が**病気の時に**、わたしが看病しました。（前些天朋友生病时，我照顾了他。）

#### 语法点2: 动 [ます形] + ながら

- **规则**: 表示同一主体同时进行两个动作，后面的动作为主要动作。接续方式为动词“ます形”去掉“ます”加“ながら”。
- **例句**:
    - 李さんはテレビを**見ながら**食事をしています。（小李边看电视边吃饭。）
    - そのことを**考えながら**歩いていました。（一边想着那件事一边走路。）

#### 语法点3: 小句(简体形) + でしょう？ [确认]

- **规则**: 表示确认的“～でしょう？”有两种用法：
    1.  确认对方更熟悉的事情（用**升调**），带有请对方告知信息的语感。
    2.  用于双方意见不同或叮问对方时（用**降调**）。
- **注意**: “～ね”仅用于双方意见一致时的确认。若用于可能意见不一致的确认，用“～ね”不礼貌，应用“～でしょう？”。
- **例句**:
    - 李さん、明日パーティーに**行くでしょう？** ↗（小李，你明天去派对的吧？）
    - このお菓子まずいね。（这点心难吃。）
        — えっ！まずい？**おいしいでしょう。** ↘（哎！难吃？好吃吧！）
    - 今日は**暑いですね。** ○（双方都觉天热）
        × 今日は**暑いでしょう？** （用于此情境不礼貌）

#### 语法点4: 动 [て形] + います ③ [反复/习惯]

- **规则**: “～ています”除表示进行（第15课）和结果状态（第16课）外，还可表示**反复或习惯性**的动作。表习惯时可用“～ます”替换。
- **注意**: 但当句子中有“～から”等表示时间起点的状语时，通常用“～ています”，而不用“～ます”。
- **参考**: 可表示现在从事的职业，用“[职业名词] + を + しています”。
- **例句**:
    - 葉子さんはアルバイトをしながら**学校に通っています**。（叶子边打工边上学。）【反复】
    - わたしは毎日**散歩しています**。（我每天散步。）【习惯】
    - わたしは先月から毎朝**太極拳をしています**。（我从上月起每天打太极拳。）○
        × わたしは先月から毎朝太極拳をします。
    - わたしは**高校の教師をしています**。（我是高中老师。）

#### 语法点5: 名 + で [原因/理由]

- **规则**: 助词“で”接在名词后，可以表示原因、理由。
- **例句**:
    - **仕事で**、楊さんと会っていたんです。（因为工作，和小杨见了面。）

#### 语法点6: 名 + と + 动 (会います/結婚します等)

- **规则**: 表示互动行为的动词（如“会います”、“結婚します”、“けんかします”），动作的另一方用助词“と”表示。
    - “会います”可用“に”或“と”，但用“と”时含有更强的**互动感**。
    - “結婚します”、“けんかします”等只能用“と”。
- **参考**: “甲は乙と～”中甲是主语；“甲と乙（と）が～”中甲、乙双方都是主语。
- **例句**:
    - わたしは**楊さんと**会っていたんです。（我和杨先生见面来着。）
    - **田中さんと佐藤さん（と）が**結婚しました。（田中先生和佐藤女士结婚了。）
